# Signal shape

Define name, externally checkable question, scope (`company` or `person`), why it is relevant to the premise, match rule, freshness and observation methods. Each method names a source surface and a query or lookup approach.

For example: "Does this company currently advertise an AE, SDR or BDR role on its own careers site or linked hiring platform?" Scope: company. Match: an accessible employer posting for a selling role. Recheck that it is open before relying on it later. Capture the observation date and publication date if available.

Record the answer as `true`, `false` or `null` (unknown), target identity, evidence summary, source URL, observation date and known event date. Note conflicting evidence. Hiring is observable; a pipeline problem remains a hypothesis.

Split mixed company/person questions. With any/all matching, evaluate the questions for the same target. "They seem like a fit" and "probably needs this" are not signals.
